# قارن — تطبيق الجوال

تطبيق لمقارنة أسعار الإلكترونيات بالسعودية: بتدوّر على منتج، بتشوف عروض
المتاجر مرتبة بالسعر، بتراقب منتج ليوصلك إشعار لما ينزل سعره، وبتاخد توصية من
الذكاء الاصطناعي إذا تشتري هلق ولا تستنى.

مبني بـ [Expo](https://expo.dev) (SDK 57) + expo-router + NativeWind، والمصادقة
عبر Clerk. الواجهة عربية بالكامل.

---

## ⚠️ اقرأ هاد أول شي

**هالمستودع نصّ المشروع بس.** التطبيق ما بيشتغل لحاله — لازم السيرفر يكون
شغّال كمان:

> **مستودع السيرفر:** https://github.com/FiezAlhagwork/backend_mobile_qaren

نزّل الاتنين بنفس المجلد:

```
my-app/
├── server/    ← من مستودع السيرفر
└── mobile/    ← هالمستودع
```

## التشغيل

### ١. السيرفر أولاً

```bash
cd server
npm install
cp .env.example .env      # وعبّي القيم
npm run dev
```

بيشتغل على المنفذ **8000**. تأكد إنه طالع بلا أخطاء قبل ما تكمّل — لو في متغيّر
بيئة ناقص بيوقف فوراً وبيقلّك اسمه.

### ٢. التطبيق

```bash
cd mobile
npm install
cp .env.example .env      # وعبّي مفتاح Clerk العام
npx expo start
```

بعدها امسح الـ QR بتطبيق Expo Go، أو اضغط `a` لمحاكي أندرويد و `i` لمحاكي iOS.

### ٣. مفاتيح Clerk لازم تكون من نفس التطبيق

هاي أكتر نقطة بتوقّع الناس:

| الملف | المتغيّر | من وين |
|---|---|---|
| `server/.env` | `CLERK_SECRET_KEY` | Clerk → API Keys → Secret key |
| `mobile/.env` | `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk → API Keys → Publishable key |

**لازم يكونوا من نفس تطبيق Clerk.** لو أخدت واحد من تطبيق وواحد من غيره، كل
طلب رح يرجع `401` وما رح تفهم ليش.

## عنوان الـ API — ما بدّك تضبطه

**بالوضع الطبيعي ما بتلمس ولا إعداد.** جوالك أصلاً بينزّل التطبيق من كمبيوترك
عبر Metro، فـ [`lib/env.ts`](lib/env.ts) بياخد نفس الـ IP وبيبدّل المنفذ لـ
8000. يعني لما تتبدّل شبكتك، بيكفي تعيد تشغيل Expo وخلص.

### الجوال مش على نفس شبكة الكمبيوتر؟

**لو رح تشغّل السيرفر على جهازك إنت** (الحالة الطبيعية): ما في شي تعمله. العنوان
بينشتق من جهازك لحالو.

**لو بدّك توصل لسيرفر على جهاز تاني أو شبكة تانية:** العناوين الخاصة
(`192.168.x.x`) ما بتنوصل من برّا الشبكة إطلاقاً. بدك نفق عام:

```bash
# على الجهاز يلي شغّال عليه السيرفر
ngrok http 8000
# أو
cloudflared tunnel --url http://localhost:8000
```

وخد الرابط العام وحطّه بـ `mobile/.env`:

```
EXPO_PUBLIC_API_URL=https://xxxx.ngrok-free.app
```

ثم **`npx expo start -c`** — متغيرات `EXPO_PUBLIC_` بتنحقن وقت البناء، وإعادة
التحميل السريع ما بتلتقطها.

> `expo start --tunnel` بينفّق **Metro بس**، مش الـ API تبعك. فلو استعملته لازم
> تحط `EXPO_PUBLIC_API_URL` كمان.

## حل المشاكل

**كل الطلبات بترجع `401`**
مفاتيح Clerk مش من نفس التطبيق. راجع الجدول فوق.

**خطأ شبكة / ما في رد من السيرفر**
- تأكد إنه السيرفر شغّال، وإنه على المنفذ **8000** (شيك `PORT` بـ `server/.env`).
- تأكد إنه الجوال والكمبيوتر على **نفس الواي فاي**.
- بعض الشبكات (شبكات الجامعات خصوصاً) بتمنع الأجهزة من تشوف بعضها — جرّب
  هوتسبوت من جوالك، أو استعمل نفق.

**`You need to be signed in to Expo Go and Expo CLI`**
سجّل دخول بالطرفية `npx expo login`، **وكمان** جوّا تطبيق Expo Go بنفس الحساب.
الاتنين مطلوبين. للتأكد: `npx expo whoami`.

**`Project is incompatible with this version of Expo Go`**
نسخة Expo Go عندك أحدث أو أقدم من SDK المشروع (57). حدّث التطبيق من المتجر.

**`متغير البيئة ... ناقص`**
ما عبّيت `mobile/.env`، أو عدّلته وما أعدت التشغيل بـ `-c`.

**`429` من Gemini**
خلصت الحصة المجانية اليومية للموديل. بدّل الموديل بـ `server/.env` — مثلاً
`GEMINI_MODEL=gemini-3.6-flash` — والحصة منفصلة لكل موديل.

**شاشة بيضا أو خطأ بعد `npm install`**
```bash
npx expo start -c
```
